Part 02

Solution: The Four-Stage Loop

AI does three things: Collect → Judge → Act. Everything else is automated.

① Task Intake

Manager enters tasks — who does what, by when

↓

② Verification

AI polls data sources, assesses task status

↓

③ Tracking

Stalled? → AI nudges the owner automatically

↓

④ Completion

Done → logged, AI briefs the manager

Part 03 · Task Intake

Where tasks come from

AI extracts tasks automatically from daily communication. No manual entry needed.

Source Tool What AI extracts
Meeting notes Google Calendar + Meet Agenda, outcomes, action items (owner + content + deadline)
Chat threads Google Chat Task keywords ("I'll handle", "by Friday", "assign to")
Email Gmail Sender, subject, task directives ("Please...", "Need by...")
Doc comments Google Docs / Sheets @mentions, comment-based tasks
Part 03 · Task Intake

What AI does

① Sync regularly

Google Calendar API · Gmail API · Google Chat API — polled on schedule

② Extract tasks

LLM parses: owner, content, deadline, delivery criteria

③ Write to task pool

Google Sheets · Notion · Airtable — grouped by owner

④ Detect conflicts

Same owner + same deadline = overlapping tasks flagged

Part 04 · Verification

Objective checks, no awkwardness

AI reads task status + cross-checks data sources. Far more objective than a human.

24h before deadline

Any clear progress made?

On deadline day

Will it ship on time?

Overdue

Is it still being actively worked on?

AI is more objective than humans

It won't skip the nudge because it feels "awkward"

Part 05 · Tracking

Stalled? AI sends the nudge

AI messages the owner automatically — no manager involvement needed.

Triggers

  • Progress stalled X hours before deadline
  • Overdue without any update
  • Key milestone silently ignored

Channels

  • Google Chat @owner
  • Gmail / email
  • WhatsApp · SMS

Immediate effect

Owners know someone's watching. Accountability and urgency spike naturally.

Part 06 · Completion

Done? AI logs and reports

Automatic record + manager briefing when a task is marked complete.

Report includes

  • Task name + owner
  • Planned deadline vs actual completion
  • Delay flag + reason if overdue
  • Format: one-liner · daily digest · weekly report

Manager's day, transformed

From "chasing people" → "reading AI summaries"

Part 10

Getting started

① Run the smallest loop first

One project, one task line. Validate the concept before scaling.

② Tell your team

Be transparent: "AI is helping me track progress." Reduces resistance.

③ Start with Tracking

If resources are limited: implement "auto-nudge on overdue" first. Biggest impact.

④ Data quality = outcome

More specific task entry = more accurate AI judgment.
